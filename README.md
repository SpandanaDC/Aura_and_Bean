# Aura & Bean ☕✨
> Enterprise-grade B2B smart-café and collegiate partnership platform featuring automated lead ingestion, role-based secure operations, and asynchronous webhook dispatching.

---

## 🚀 Architecture & Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS, Vite.
* **Backend:** Node.js, Express, Mongoose.
* **Database:** MongoDB (Local / Atlas).
* **Automation:** Conditional event-driven webhook pipeline for high-tier enterprise inquiries.

---

## 🛠️ Key Features
1. **Public Partnership Portal:** High-converting landing page allowing corporate campuses and tech parks to submit automated coffee station inquiries.
2. **Dynamic Tier Classification:** Real-time footfall analysis that categorizes inquiries into standard queues or **✨ Flagship Spaces**.
3. **Automated Webhook Dispatcher:** High-value Tier-1 inquiries automatically trigger instant event notifications and server logs, bypassing manual review latency.
4. **Secure Ops Dashboard:** Password-protected administrative portal (`admin@auraandbean.com`) for managing lead pipelines and manual sync dispatching.
